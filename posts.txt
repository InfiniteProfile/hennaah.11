# HOW TO ADD POSTS
# Paste a link to a photo or video. Photo/video is detected automatically.
# Separate each post with a dollar sign ($).
# The TOP of this file is the NEWEST post. Old posts are never removed.
# Several PHOTO links inside one $ block become one swipeable carousel.
# Lines starting with # are ignored.
# GitHub links (github.com/.../blob/main/...) work exactly as they are.
#
# Example (delete the # to use it):
# https://github.com/InfiniteProfile/hennaah.11/blob/main/Post/new-video.mp4
# $
# https://github.com/InfiniteProfile/hennaah.11/blob/main/Post/photo1.jpg
# https://github.com/InfiniteProfile/hennaah.11/blob/main/Post/photo2.jpg
# $
# https://example.com/another-photo.jpg
